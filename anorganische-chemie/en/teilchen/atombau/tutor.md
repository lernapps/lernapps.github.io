## Exercises

### atom-bauen (interactive exercise AtomBuilder)

- Link: [./#atom-bauen](./#atom-bauen), in the section „Practice“
- What to do: Learners set the number of protons, neutrons and electrons for a given element with plus and minus buttons and check their atom.
- Answer format: Three whole numbers: protons, neutrons, electrons.
- What counts as right: The number of protons is the atomic number, the number of electrons equals the number of protons (neutral atom), the number of neutrons is the mass number minus the number of protons.
- Typical mistakes and the app's message:
  - The number of electrons differs from the number of protons, so the atom would be charged.
  - The mass number is entered as the number of neutrons.
  - The number of protons does not match the atomic number of the element.
- Tasks by number, 1 to 10: each a different one (the app shows “Task no. …”):
  - [Task no. 1](./?atom-bauen=1#atom-bauen): Build a neutral atom of Hydrogen (H) with mass number 1. Set the number of protons, neutrons and electrons. → Solution: Hydrogen has 1 proton, 0 neutrons and 1 electron.
  - [Task no. 2](./?atom-bauen=2#atom-bauen): Build a neutral atom of Helium (He) with mass number 4. Set the number of protons, neutrons and electrons. → Solution: Helium has 2 protons, 2 neutrons and 2 electrons.
