Formulas and reactions

You write elements and compounds with symbols and formulas, recognise chemical reactions and write simple reaction equations.

  1. Symbols and formulas Every element has a symbol, every compound a formula. This is how you read and write them.
  2. Chemical reactions In a chemical reaction new substances are formed. This is how you tell it from a change of state.
  3. Reaction equations A reaction equation shows which substances react. There must be the same number of atoms on both sides.
